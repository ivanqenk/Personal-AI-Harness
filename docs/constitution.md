# Constitución del proyecto

> Rellena esto una vez, al empezar el proyecto. Son los principios que ningún spec,
> diseño o implementación puede contradecir. Si algo aquí choca con una spec concreta,
> gana la constitución.

## Principios innegociables

1. <ej. "Nunca se guardan credenciales en texto plano">
2. <ej. "Toda función pública tiene test">
3. <ej. "El CLI/API nunca rompe compatibilidad hacia atrás sin versión mayor">
4. <ej. "Sin dependencias nuevas sin justificar por qué">
5. <ej. "El código se escribe para leerse, no para presumir de listo">
6. <...>

## Fuera de alcance del proyecto (a nivel global, no por feature)
- <qué no se va a construir nunca en este proyecto, independientemente de la feature>

## Notas
- Estos principios son deliberadamente pocos y estables. Si sientes que necesitas
  cambiarlos con frecuencia, probablemente esa regla pertenece a `rules/`, no aquí.
